## Goal
`PerceptionPipeline: Perception` turns frames into identity-aware track events using Apple Vision and an on-device InsightFace embedding, exercised on fixture videos in the Simulator. The demo needs: a consented person recognized within 1 s at 1–2 m, strangers never named, approach / arrive / leave events, bearing bands and distance bins.

## Model
InsightFace `w600k_mbf.onnx` from the `buffalo_sc` pack (https://github.com/deepinsight/insightface/releases, asset `buffalo_sc.zip`; also mirrored on Hugging Face; ~13 MB). Save it as `Familiar/Resources/models/w600k_mbf.onnx` and add `MODEL_LICENSES.md` (non-commercial research license). Input `1×3×112×112` float32, **RGB**, `(x − 127.5) / 127.5`, NCHW; output 512 floats → L2-normalize. Read the input and output names from the ORT session (`inputNames()` / `outputNames()`); never hardcode them. If the file cannot be obtained, use OpenCV Zoo SFace `face_recognition_sface_2021dec.onnx` (Apache-2.0, 128-d, same alignment, threshold ≈ 0.36) with `modelID = "sface"`, and say so.

## Files
- **`FaceDetector.swift`:** `VNDetectFaceRectanglesRequest` with `revision = VNDetectFaceRectanglesRequestRevision3` set explicitly (roll / yaw / pitch in **radians**; pitch is nil otherwise), run through `VNImageRequestHandler(cvPixelBuffer:orientation:)` on a ≤ 960 px-wide downscale; then `VNDetectFaceLandmarksRequest` with `revision = VNDetectFaceLandmarksRequestRevision3`, `constellation = .constellation76Points` set explicitly, and `inputFaceObservations` = the rectangles result (detection runs once). Convert Vision's bottom-left normalized rects to top-left normalized `CGRect`; landmark points via `VNImagePointForFaceLandmarkPoint` (they are normalized to the face box). Use the `VN*` classes, not the new Swift `DetectFaceLandmarksRequest` (out-of-range landmarks reported on iOS 26). Serial queue; drop frames while busy; ≤ 15 fps.
- **`FaceTracker.swift`:** greedy IoU association (> 0.3) frame to frame; tentative → confirmed after 3 hits; lost after 2.5 s unseen. Per track: box history (time, height px), identity votes, top-8 `FaceEmbedding`s ranked by `quality × yawDiversity`, mouth-openness series (inner-lip vertical gap ÷ face height, last 1.5 s), `isFacingUser` = |yaw| < 25°.
- **`FaceAligner.swift`:** five points from landmarks — left pupil, right pupil, nose tip (`nose` region center or the last `noseCrest` point), outer-lip left and right corners (min / max x of `outerLips`) — mapped onto the ArcFace 112×112 template `(38.2946, 51.6963) (73.5318, 51.5014) (56.0252, 71.7366) (41.5493, 92.3655) (70.7299, 92.2041)` with an Umeyama similarity transform (least-squares rotation + uniform scale + translation). Fallback when the solve is degenerate: rotate so the eyes are level, scale the inter-pupil distance to 35.24 px, translate the eye midpoint to (55.9, 51.6). Warp from the **full-resolution** frame with Core Image into a 112×112 BGRA `CVPixelBuffer`. Also produce the 256×256 thumbnail JPEG (face box with 20 % margin from the full-res frame, quality 0.8).
- **`OnDeviceEmbedder.swift`** (`EmbeddingProvider`, `modelID = "w600k_mbf"`, `dimension = 512`): one `ORTEnv(loggingLevel: .warning)` and one `ORTSession` created lazily; CPU execution provider first; optional CoreML EP behind a flag (`appendExecutionProvider("CoreML", providerOptions: ["ModelFormat": "MLProgram", "MLComputeUnits": "CPUAndNeuralEngine", "RequireStaticInputShapes": "1"])`) — keep whichever runs without "multiple partitions" warnings. Preprocess BGRA → RGB float planes; fp32 I/O. **`ModalEmbedder.swift`** (same protocol): `POST $MODAL_EMBED_URL`, headers `Modal-Key` / `Modal-Secret`, body `{"image_b64": JPEG of the aligned 112×112}`, parse `{"embedding": [...]}`, 2 s timeout. **`FakeEmbedder`** for tests (deterministic vector from a label).
- **`Matcher.swift`:** cosine against every embedding of every person in `GalleryProvider.gallery()` whose `modelID` matches; `bestScore` and `secondBestPersonScore`; accept if `best ≥ T` (default 0.40, injectable) **and** `best − secondBest ≥ 0.08`; identity lock after 3 consistent votes; a conflicting vote decrements; unlock below 1 vote.
- **`Spatial.swift`:** `bearing(centerX:, hFOV:)` → degrees `atan((cx − 0.5) · 2 · tan(hFOV/2))` and a band by frame fraction (center 25 % ahead, next 25 % each left / right, outer far left / far right); `distance(faceHeightPx:, frameHeightPx:, vFOV:)` → meters via `0.20 m / (2 · tan((h/H) · vFOV / 2))`; bins close < 1.5, medium 1.5–3, far > 3 (thresholds injectable for calibration).
- **`Trajectory.swift`:** approaching = bin decreased or box height +25 % over 1.5 s with ≥ 3 observations; arrived = close and stable 1 s; left = confirmed track lost > 2.5 s; each known event once per episode.
- **`PerceptionPipeline.swift`:** wires the above; `subscribe()` via `EventBus`; `snapshot(tracks:preview:)` every 5th frame with a downscaled `CGImage`; embedding scheduler (0.5 s per track until identity locks, then 3 s; unknown tracks 1 s for 10 s, then 5 s; `requestBurst` = 4/s for the given seconds); `assignIdentity` locks a track to a person immediately; `unknownCountChanged` when the number of confirmed unknown tracks changes; `bestEmbeddings` from the track's top-8; thread-safe snapshot getters; re-reads `gallery()` at every match.
- `PhoneCameraFrameSource`: only call `setExposurePoint` with the largest face's center.
