## Goal
The heart of the demo: remembering a person by spoken consent, storing them, creating a contact, and every screen.

## Memory
- **`JSONPeopleStore`** (`@MainActor`, `PeopleStore`): `Documents/people.json` (array of `Person`), `Documents/thumbs/<id>.jpg`, `Documents/consents/<id>.wav`; atomic writes; `gallery()` served from a lock-protected snapshot rebuilt on every change (embeddings grouped by `modelID`; the gallery's `modelID` is the active embedder's); `changes()` via `EventBus`; `remove(id:)` deletes the row, both files, and calls `ContactsBridge.delete` when `contactIdentifier` is set. "Reset people" in Demo controls removes all (and never touches the TTS cache).
- **`ContactsBridge`** (`CNContactStore`): `requestAccess(for: .contacts)` (iOS 18 limited access is fine: contacts we create are visible to us). `CNMutableContact` with `givenName = person.name`, `organizationName = "Familiar"`, `jobTitle = "Met via Familiar · HackTX · Oct 25 2026"`, `imageData = thumbnail`, `phoneNumbers` when present. **Never set `note`**: it requires an Apple-approved entitlement and the save fails without it. Save with `CNSaveRequest.add(_:toContainerWithIdentifier: nil)`; return `contact.identifier`. `delete(identifier:)` fetches `unifiedContact(withIdentifier:keysToFetch:)` and deletes through a save request. `call` opens `tel://<digits>`, `text` opens `sms:<digits>` (never sends).
- **`MeetingContext`:** `CLLocationManager` when-in-use, one fix at launch, one `CLGeocoder` reverse lookup cached for the session; the Settings `placeName` overrides it ("HackTX, UT Austin").

## Intelligence
- **`RegexNameExtractor`:** patterns `\b(?:I'm|I am|my name is|this is|it's|call me)\s+([A-Z][a-z]+(?:\s[A-Z][a-z]+)?)` and `\b([A-Z][a-z]+) here\b`, applied to `other`-attributed segments only; stop list (the user's name, Hi, Hey, Nice, Okay, Yes, No, Sorry, Thanks, Good); confidence 0.9 for "my name is" / "I'm", 0.7 otherwise; `source = "regex"`.
- **`FoundationModelsNameExtractor`** behind `#if canImport(FoundationModels)` + `#available(iOS 26, *)`: proceed only if `SystemLanguageModel.default.availability == .available`; `LanguageModelSession(instructions:)` whose instructions open with a role statement ("You help a blind user remember people they meet …") and never contain transcript text; call `session.prewarm()` when a conversation starts; `respond(to: prompt, generating: NameGuessGen.self, options: GenerationOptions(samplingMode: .greedy))` with `@Generable struct NameGuessGen { @Guide(description: "First name the OTHER person gave, or empty if none") var name: String; @Guide(description: "0 to 1") var confidence: Double }`; the prompt is the last 90 s formatted `OTHER: … / USER: …`, trimmed to roughly 1,500 tokens. Catch every `LanguageModelSession.GenerationError` (guardrail, refusal, rateLimited — the camera being open counts as heavy load — context window, locale) and return nil so the race continues. Same pattern with `@Generable enum YesNoGen { case yes, no, unclear }`.
- **`MetaModelClient`** (URLSession, one shared session, warm-up call at launch): `POST https://api.meta.ai/v1/chat/completions`, headers `Authorization: Bearer <META_MODEL_API_KEY>`, `Content-Type: application/json`. Body:
  ```json
  {"model": "muse-spark-1.3", "reasoning_effort": "low", "max_completion_tokens": 400,
   "prompt_cache_key": "familiar-name-v1", "safety_identifier": "<sha256 of identifierForVendor>",
   "messages": [{"role": "system", "content": "…"}, {"role": "user", "content": "OTHER: … USER: …"}],
   "response_format": {"type": "json_schema", "json_schema": {"name": "IntroducedName", "strict": true,
     "schema": {"type": "object", "additionalProperties": false,
       "properties": {"name": {"type": ["string", "null"]}, "confidence": {"type": "number", "minimum": 0, "maximum": 1}},
       "required": ["name", "confidence"]}}}}
  ```
  `reasoning_effort` is `"low"` for names and `"minimal"` for yes/no and intent (`"none"` is rejected). Parse `choices[0].message.content` (a JSON string) only when `finish_reason == "stop"`; one retry honoring `Retry-After` on 429 / 503; timeouts 15 s for names (background) and 4 s for yes/no and intent. Yes/no schema `{"answer": {"enum": ["yes", "no", "unclear"]}}`; intent schema `{"intent": {"enum": [...]}, "name": {"type": ["string", "null"]}}`. If the strict validator rejects `["string", "null"]`, use `"type": "string"` with `""` meaning null. Never use the `-contributor` model (it trains on inputs).
- **`CompositeNameExtractor`:** regex first (return immediately when confidence ≥ 0.7); otherwise race Foundation Models and Meta with a task group, first result with confidence ≥ 0.6 wins (Foundation Models preferred on a tie), 15 s overall. **`NameGuessCache`:** a background loop started by the flow coordinator — on each new `other` final segment matching a name pattern, and every 20 s while an unknown track is close, refresh the guess for the current track-session.
- **`YesNoClassifier`:** rules first — yes: yes, yeah, yep, yup, sure, okay, ok, of course, go ahead, fine, absolutely, that's fine; no: no, nope, nah, rather not, don't, I'd rather not, no thanks; anything else → Foundation Models, then Meta (4 s) → `.unclear`.

## ConsentFlow (publishes `ConsentState`; `@MainActor` class or actor)
`begin(confirmFirst:)`: if `confirmFirst` → `confirmingWithUser`: speak "Want to remember them?" (priority 0, audience user) and wait ≤ 6 s for a yes from the segments via `YesNoClassifier` or `tapAnswer(true)`; no or timeout → `idle`. Then **`gathering(track)`**: target = the unknown track with `isFacingUser`, largest `faceHeightPx` (tie → highest `mouthOpenness` variance); `perception.requestBurst(track:, seconds: 2)`; need ≥ 3 `bestEmbeddings` with `quality ≥ 0.3` (injectable) within 2 s, else speak "Could you look toward me for a second?" and wait ≤ 4 s more; target lost → `cancelled("They seem to have left. Nothing saved.")`. Meanwhile pre-synthesize both question variants with `speaker.prewarm`. **`asking(name)`**: name = cached guess if confidence ≥ 0.7 and it is not the user's name; `cueGate.consentActive = true`; show `ConsentCardView`; `clipStart = now`; speak the question (priority 0, `audience: .otherPerson`). **`listening`**: ≤ 6 s; collect final segments after the playback window; yes or `tapAnswer(true)` → `saving`; no or `tapAnswer(false)` → `declined`; unclear → one re-ask "Sorry, was that a yes?" (≤ 4 s) then decide; timeout → `declined`. **`saving`**: `Person` with the gathered embeddings, the best thumbnail, `ConsentRecord(kind:, askedText:, replyTranscript:, clipURL:)` where the clip is the ring-buffer slice `[clipStart − 0.5 s, replyEnd + 0.7 s]` written as WAV, `MeetingContext`; `perception.assignIdentity`; `peopleStore.add`; `contacts.create` (store the identifier); speak "Saved. {Name} is in your contacts."; publish `done(person)`; Home navigates to the Person detail. No name → speak "What should I call you?" (otherPerson), listen ≤ 6 s, regex / Foundation Models on the reply; still nothing → save as "Someone I met" and let the user rename in Person detail. **`declined`** → speak "Okay, nothing saved." and discard everything held in memory. `cancel()` from any state. Always reset `cueGate.consentActive` and hide the card.

## CommandRouter
Subscribes to every `CommandSource` (wake word, buttons, gestures) and to the goodbye signal: `whoIsHere` → `RollCall.phrase(perception.currentTracks())` → speak (priority 1, earcon); `rememberThem` → `consentFlow.begin(confirmFirst: false)`; goodbye → `begin(confirmFirst: true)` only if an unknown track is close and no flow is active (60 s cooldown); `setMode`, `mute` / `unmute` (gate + "Muted." / "Unmuted."); `call(name)` / `text(name)` → `peopleStore.find` (case-insensitive prefix) → "Calling X." then `contacts.call`, else "I don't know anyone called X."; `whereIs(name)` → from `currentTracks` or a last-seen memory ("I last saw X on your left."); `cancel` → consent cancel + `speaker.stopAll()`; `repeatLast`. **Volume buttons:** `AVCaptureEventInteraction` (AVKit, iOS 17.2+) attached through a `UIViewRepresentable` in Home; events are delivered only while an `AVCaptureSession` is running, so in glasses mode keep a minimal phone capture session alive; primary = who's here, secondary = remember them, swappable in Settings.

## UI (SwiftUI, VoiceOver complete)
- **`ReadinessView`** (first screen until all rows are green; sequential requests): camera, microphone, speech recognition (only when the SFSpeech fallback is used), contacts, location; rows for speech assets (download with progress), Foundation Models availability text, ElevenLabs key present, Meta key present, audio route, embedding model loaded, glasses registration (placeholder until S6).
- **`HomeView`** (complete S1's skeleton): status line "{mode} · {route} · {source} · mic ▮▮▮", mode picker, Mute, **Who's here?**, **Remember them**, source picker, links.
- **`PeopleView`**: list with thumbnail, name, "met at {place}, {date}", swipe to remove (confirm). **`PersonDetailView`**: thumbnail, name (editable), phone (editable), consent kind and transcript, **Play consent clip** (`AVAudioPlayer`), Call, Text, Remove.
- **`SettingsView`**: user name, place name, cue toggles (speaking / wave / smile, disabled until implemented), voice provider, embedding provider + threshold slider (0.25–0.60) + minimum face px, audio route, loudness calibration button, volume-button mapping.
- **`ConsentCardView`**: full-screen sheet with the question in large type and two large buttons YES / NO (`tapAnswer`).
- **`DemoControlsView`** (long-press on the Home title): reset people, run the script, force the consent flow, re-prewarm, show fps and latency.
- **`JudgeView`**: finish S1's skeleton — per-track score, last 3 utterances, mode, listening state, mic meter, route, fps, last 10 s of transcript, event log, the banner.
